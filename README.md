### 📋 Pré-requisitos

* Visual Studio Code


### 🔧 Instalação

* Faça o download ou clone o repositório.
* Abra o arquivo index.html no seu navegador.
* Edite como quiser.

## ⚙️ Funcionalidades

- 🎵 **Música de fundo**: Música usada ao clicar para entrar.
- 🌌 **Animações com partículas**: Fundo com partículas via `particles.js`.
- 🎀 **Estilo Hello Kitty**: Visual customizado com ícones, cursores e tema rosa/plum.
- 🧠 **Perfis interativos**: Avatares com hover animado e links para redes sociais.
- 💬 **Tooltips**: Tooltips animados sobre badges e ícones com `Tippy.js`.
- 📸 **Tilt Effect** (em planejamento): Adição possível com `VanillaTilt.js`.
- 🛡️ **Prevenção de inspeção/cópia**: Bloqueia DevTools, clique direito e seleção de texto.
- 🖼️ **Design responsivo**: Adaptado para desktop e dispositivos móveis.
